# RnD

RnD means research and development. This repository is the base for the research and development projects we work on.

## Current work

### Handwritten Assignment Generation System

We are working on a system that can prepare a complete assignment and save it as a PDF written in a handwriting style. The goal is to make it look like a student's handwritten assignment, not just put typed answers on a page.

The student can provide the assignment questions with an already solved copy of the same assignment. This solved copy is the main reference. The system should look at how each answer is explained, which steps and methods are used, how much detail is given, and how the answers are arranged. If the reference is handwritten, it can also show how the work is written on the page. The system should use these details when preparing the assignment.

This reference is important because answers can be different even when they are about the same question. An AI tool may use one method, a textbook may use another, and a teacher may teach a different method in class or in the slides. These answers may all be correct, but the student may need to follow the method taught in class. The system should make the answers in the way the student asks.

An already solved copy will not always be available. In that case, the student can provide the questions and a prompt. The prompt can explain which method to follow, what points and steps to include, and what answer style to use. The system should use these instructions to prepare the answers and create the final PDF.
