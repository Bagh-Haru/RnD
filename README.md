# RnD

RnD means research and development. This repository is the base for the research and development projects we work on.

## Current work

### Handwritten Assignment Generation System

We are working on a system that can make an assignment PDF in a handwriting style.

The user can give the assignment questions with a solved copy as a sample. The system will use it to understand how the answers should be written and which method to follow.

Sometimes, a solved copy may not be available. In that case, the user can give the questions and a prompt that explains the method and answer style they want.

We need this because an AI, a book, and a teacher can explain the same answer in different ways. The system should follow the method and style the user needs.
