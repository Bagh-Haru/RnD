# RnD

RnD means research and development. This repository is the base for the research and development projects we work on.

## Current work

### Handwritten Assignment Generation System

We are working on a system that can make a full assignment PDF that looks handwritten.

The user can give the assignment questions with a solved copy of the same assignment. This solved copy is the main reference. The system should study how the answers are written, which steps and methods are used, and how the work is presented. It should use this to prepare the answers in a similar way.

We need this because an AI tool, a book, and a teacher's slides can explain the same topic in different ways. A teacher may expect one method, while an AI answer or another book may use a different one. The user should be able to tell the system which method to use and what to include in the answers.

Sometimes, the user may not have a solved copy. In that case, they can give the questions and a prompt that explains the method, answer style, and other instructions. The system will use these details to prepare the assignment PDF.
